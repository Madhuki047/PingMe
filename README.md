# PingMe
PingMe is a full-stack, elderly-focused care app designed to provide simple daily check-ins, emergency alerts, and easy access to important information.

# Elderly Healthcare App

Industry-ready elderly healthcare web application built with Django REST Framework and React.

## Overview
This project aims to support elderly users with healthcare-related tasks such as appointment management, reminders, and user-friendly digital interaction.

## Tech Stack
- Frontend: React
- Backend: Django REST Framework
- Database: To be integrated
- Version Control: Git and GitHub
